# FacoNote Frontend

Interface web pour l'encodage rapide, le calepinage et l'optimisation de débit d'atelier Facozinc.

## Démarrage Local

**Prérequis :** Node.js

1. Installer les dépendances :
   ```bash
   npm install
   ```

2. Lancer l'application en mode développement :
   ```bash
   npm run dev
   ```

3. Construire pour la production :
   ```bash
   npm run build
   ```
